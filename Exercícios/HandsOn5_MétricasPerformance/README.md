# Métricas de Performance de Classificação
### Detecção de Diabetes
**Desenvolva um modelo que apresente boas métricas de performance para detectar pacientes com diabetes.**

<u>Roteiro:</u>
- 1. Importe a base de dados ``diabetes.csv``. 
- 2. Realize as etapas de Preparação e Análise Exploratória dos dados.
- 3. Desenvolva um modelo de Regressão Logística utilizando as variáveis disponíveis.
- 4. Avalie a performance do modelo utilizando as métricas aprendidas nas aulas.
- 5. Ajuste 4 novos modelos utilizando diferentes grupos de variáveis explicativas e avalie a performance deles.
- 6. Interprete os coeficientes do modelo.

``Base: diabetes.csv``
