# Regressão Logística
### Base Iris
**Treine um modelo de regressão logística e calcule sua acurácia**

<u>Roteiro:</u>
- 1. Importe a base ``iris.csv``. 
- 2. Faça a análise exploratória dos dados.
- 3. Treine o modelo de regressão logística.
- 4. Crie uma coluna chamada Y_Estimado usando o corte de 0,5 na variável g(z).
- 5. Calcule a acurácia do modelo.
- 6. Interprete os coeficientes do modelo.

``Base: iris.csv``
