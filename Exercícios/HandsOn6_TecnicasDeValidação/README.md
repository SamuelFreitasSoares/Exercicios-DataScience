# Técnicas de Validação
### Custos de Saúde
**Treine e valide um modelo para prever o custo de saúde de cada colaborador da empresa.**

<u>Roteiro:</u>
- 1. Importe a base de dados ``base_custos_saude.xlsx``. 
- 2. Faça uma análise exploratório inicial e uma análise de correlação com o Target.
- 3. Treine um modelo adequado para o problema.
- 4. Valide o modelo usando Validação **Out of Sample**/Holdout, Validação **Out of Time** e Validação **Cruzada**.
- 5. Qual sua conclusão a respeito do melhor tipo de validação para o problema? Qual sua estimativa para a medida de performance esperada do modelo quando for usado para prever o custo do plano de saúde?.

``Base: base_custos_saude.xlsx``
