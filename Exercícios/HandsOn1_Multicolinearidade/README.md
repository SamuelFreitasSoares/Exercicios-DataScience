# Regressão Linear
### Multicolinearidade
**Resolva um problema de multicolinearidade**

<u>Roteiro:</u>
- 1. Em um novo notebook, importe a base **base_funcionarios_v3.csv**. 
- 2. Ajuste um modelo de regressão linear para a variável resposta **Salário** utilizando as variáveis explicativas **Anos de Educação Superior**, **Tempo na Empresa** e **Tempo de Carreira**.
- 3. Avalie a existência de **multicolinearidade**.
- 4. Selecione e remova uma das variáveis explicativas e ajuste um novo modelo.
- 5. Interprete os coeficientes do modelo.
